# Подключение ElevenLabs (замена голоса в видео)

ElevenLabs меняет голос в готовом видео: речь, интонация, темп и эмоции остаются из исходника,
меняется тембр. Работает в двух местах:

1. Кнопка **«Заменить голос»** под готовым видео (и в библиотеке).
2. **Автопереозвучка** в режиме «Видео → видео» (блок «Звук» → «Переозвучить»).

Модель — `eleven_multilingual_sts_v2` (официально поддерживает русский). Голоса — вся библиотека
ElevenLabs, в том числе тысячи русских голосов от носителей; по умолчанию Marina (жен.) и Nikolay (муж.).
Раньше ElevenLabs шёл через fal.ai: там нельзя выбрать модель, и русская речь выходила с английским акцентом.

Без ключа ElevenLabs движок в интерфейсе серый (подсказка «Нужен ключ ElevenLabs»), Chatterbox HD
(через fal.ai) работает как раньше.

## 1. Ключ

1. https://elevenlabs.io → профиль → **API Keys** → **Create API Key**.
2. Имя — например `MediaGenerator`. Включите **Restrict key** и дайте права:
   - **Voice Changer** (Speech to Speech) — доступ;
   - **Voices** — чтение (каталог голосов в приложении).
   Остальное не нужно. Право **User: read** необязательно (если оно есть, проверка ключа идёт через него же).
3. Скопируйте ключ (`sk_...`) — повторно ElevenLabs его не покажет.

## 2. Куда вставить

1. Войдите **админом** → **Настройки** → API-ключи → карточка **ElevenLabs** → **Добавить ключ** → **Сохранить**.
2. Приложение проверит ключ бесплатным запросом (`GET /v1/user`). Ключ шифруется AES-256-GCM, как остальные.
3. Ключ админа автоматически работает у всех пользователей (как ключи OpenRouter и fal); новым
   пользователям он копируется при регистрации.

## 3. Цена

- ≈ **$0.12 за минуту звука**, пропорционально длине (без округления до минуты): 22 сек стоили 216 кредитов
  при тарифе на 40 000 кредитов в месяц (замер 2026-10-25). Ролик 30 сек ≈ $0.06.
- Списывается с кредитов тарифа ElevenLabs. Кончились кредиты — замена голоса вернёт понятную ошибку
  «На аккаунте ElevenLabs закончились кредиты».
- MediaGenerator списывает с пользователя **оценку** (секунды × $0.12 / 60), только за успешные задачи.
  Сверка: https://elevenlabs.io/app/usage.

## 4. Ограничения

- Один запрос — до **5 минут** звука; длиннее приложение не отправляет (просит обрезать видео).
- Голос из библиотеки может пропасть (автор удалил или скрыл его) — тогда ошибка «Этот голос недоступен»,
  выберите другой.
- Голос «русский проверен» в каталоге — автор подтвердил русский именно для этой модели; такие звучат чище всего.
- Своим образцом голоса в ElevenLabs пользоваться нельзя (для этого есть Chatterbox HD через fal.ai).

## 5. Тонкие настройки (в интерфейсе — «Тонкие настройки»)

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Стабильность (`stability`) | 50% | выше — ровнее, ниже — эмоциональнее |
| Похожесть на голос (`similarity_boost`) | 75% | насколько точно держаться тембра голоса |
| Выразительность (`style`) | 0% | усиливает манеру голоса, может снизить стабильность |
| Усиление голоса (`use_speaker_boost`) | вкл | ближе к оригиналу голоса |
| Убрать фоновый шум (`remove_background_noise`) | вкл | чистит музыку/шум исходника; на русской речи дал лучший результат |

Последний выбранный голос и настройки запоминаются в браузере.
